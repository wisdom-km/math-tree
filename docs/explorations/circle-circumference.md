## 2. 教学目标与结论

**一句话教学目标：**  
让孩子通过滚动圆轮、记录多组「周长 / 直径」数据，自己发现「任意圆的周长总是直径的 3 倍多一些」，从而认识圆周率 π，并会用 C = πd 或 C = 2πr 求周长。

**孩子最后要自己填出的结论（程序不先给）：**

1. 填空：周长大约是直径的 **___** 倍。（期望：3 倍多一些 / 约 3.14）
2. 句式：「我发现 ______，因为 ______。」  
   期望大意：周长 ÷ 直径 的比值差不多一样（约 3.14），所以任意圆的周长与直径的比值是一个固定的数。
3. 揭示后能复述：这个固定的数叫**圆周率**，用字母 **π** 表示；应用时常取 **π ≈ 3.14**；公式 **C = πd** 或 **C = 2πr**。

## 4. 状态模型（单一数据源）

所有视图（轮子、刻度、红点、表、公式、填空回显）只读这一份状态并派生；禁止第二份「显示用副本」。

### 4.1 核心状态（可写）

| 字段 | 类型 | 说明 | 可拖/可改？ | 范围与限制 |
| --- | --- | --- | --- | --- |
| `step` | 0–9 | 当前骨架步骤 | 步骤条/「下一步」 | 进入条件见第 5 节 |
| `d` | number | **直径**（唯一核心参数） | 是：拖圆边两端点，或键盘输入 | **2.0–10.0 cm**，步进 0.1；默认 4.0。限制理由：地面尺在一屏内能显示至少约 3.5 个直径长度（πd），刻度仍可读；过小难拖，过大滚一圈出屏 |
| `rollAngle` | number (rad) | 已滚动角 | 滚动手势写入 | 0 … 2π；满一圈锁死 |
| `isRolling` | bool | 是否正在拖滚 | 手势 | — |
| `rollLocked` | bool | 本圈已滚满锁定 | 满圈自动 true | 换 `d` 或点「再滚一次」解锁并清轨迹 |
| `table` | Row[] | 数据表 | 「加入数据表」追加 | 最多 8 行；同 d 可重复但提示「已经有过接近的直径」 |
| `guess` | {low, high, likely} | 先猜三估值 | 步骤 2 写入 | 单位 cm；针对情境中「铁皮多长」 |
| `handVotes` | {value → count} | 举手分布 | 老师点候选人 +/- | 步骤 2、可选步骤 5 |
| `patternBlank` | string \| null | 「___ 倍」填空 | 步骤 5 | 接受「3」「3倍多一些」「约3.14」等（见校验） |
| `discoveryText` | {find, because} | 「我发现…因为…」 | 步骤 5 | 非空才可进步骤 6 |
| `piRevealed` | bool | 是否已揭示 π | 步骤 6 置 true | 揭示后活公式可见 |
| `verify` | {dPred, cPred, done} | 验证轮预测 | 步骤 7 | 先算后滚 |
| `mode` | `student` \| `teacher` | 界面模式 | 启动参数/顶栏切换 | student 隐藏提问卡 |
| `confusionMode` | bool | 易混并排 | 步骤 9 或老师手动开 | 见第 6 节 |
| `easter` | {nSides} | 割圆术边数 | 步骤 9 | 6,12,24,48,96 |
| `history` | Snapshot[] | 撤销栈 | 撤销/重置 | 最多 30 步 |

### 4.2 派生量（只读计算）

| 派生 | 公式 / 规则 |
| --- | --- |
| `r` | `d / 2` |
| `C` | `π * d`（内部用 `Math.PI`；**展示**在揭示前用测量值 `rolledLength`，揭示后公式用 **3.14** 与教材一致，可切换「更精确」显示 3.1416… 但不进主计算） |
| `rolledLength` | `(rollAngle / (2π)) * C`；满圈 = 当前测量周长 |
| `ratio` | `rolledLength / d`（加入表时冻结为该行的 C÷d） |
| `redPoint` | 轮子圆周上角位置；地面印记数组随滚动追加 |
| `wheelX` | 轮心水平位置 = 起点 + `rolledLength`（纯滚动无打滑） |

### 4.3 数据表行结构

```text
Row {
  id: string
  label: string        // 默认「圆1」「圆2」…；可改成「杯盖」「光盘」等（大键盘+预设名）
  d: number            // cm，加入时快照
  C: number            // cm，加入时 = 当时 rolledLength（须已满一圈）
  ratio: number        // C/d，保留两位小数显示
  source: "roll"       // 本课只允许滚动实测加入
}
```

表头固定四列：`物品/序号 | 直径 d/cm | 周长 C/cm | 周长÷直径`。  
与教材例 2 实验表对齐（物品名称、周长、直径、比值保留两位小数）。

### 4.4 约束式沙盒：什么能拖、什么锁定

| 可操作（1 个核心 + 滚动） | 锁定（本课不开放） |
| --- | --- |
| 直径 `d` | 圆心位置（竖直固定在地面上） |
| 滚动（拖轮或拖地面） | 任意改变 π、改公式字母 |
| 数据表加入 / 删最后一行 | 自由画线、改刻度单位 |
| 步骤 5/7 填空与预测输入 | 步骤 3 前显示公式 |

## 5. 逐步交互（骨架 0–9）

每步统一写五块：**界面 / 孩子能做 / 程序反馈 / 进入下一步条件 / 老师提问卡 + 举手**。

---

### 步骤 0 · 回忆（约 1–2 分钟）

**界面显示什么**

- 主舞台：一个圆，标出圆心 O、一条半径 r、一条直径 d（术语与教材 p55–56 一致）。
- 短提示：「同一个圆里，直径长度是半径的 ____。」
- 右侧：迷你任务卡，无数据表。

**孩子能做什么**

- 拖半径端点，圆大小变；直径线段自动 = 2r 并高亮。
- 点选填空：`2` / `一样长` / `一半`（三选一触控大按钮）。

**程序如何反馈**

- 拖动时旁注实时：`d = 2 × r`，数字随 r 变（活公式雏形，只出现 r、d）。
- 选对「2」：直径闪一下青绿，进入解锁「下一步」。
- 选错：不弹「错了」；把直径与两条半径并排叠在直径上，让孩子自己看。

**进入下一步条件**

- 正确选出「直径是半径的 2 倍」，或老师点「跳过回忆」（记日志）。

**老师提问卡（2–3 条）**

1. 圆心决定圆的什么？半径决定圆的什么？
2. 同一个圆里，有多少条半径？它们一样长吗？
3. 如果只给你直径 6 cm，半径是多少？不用再量为什么？

**投屏举手**  
本步不做全班举手；个别叫答即可。

### 步骤 1 · 情境（约 2 分钟）

**界面显示什么**

- 少文字真问题（不出现「周长」「π」）：圆桌面裂了，要在边缘**箍一圈铁皮**——铁皮要多长？
- 主舞台静帧：圆桌俯视示意 + 一段「铁皮」弯成弧（未给出长度）。
- 旁白气泡（可点开）：可以绕绳量、也可以滚一圈量（对应教材例 1 的量法，不抄原文）。

**孩子能做什么**

- 点「用滚动的办法试试」进入步骤 2。
- （可选）点「绕绳示意」看 3 秒动画：绳子围一圈拉直与滚动结果将在后面对照——第 1 版可只做滚动，绕绳留钩子。

**程序如何反馈**

- 不给数值；铁皮长度处显示「？」。

**进入下一步条件**

- 点击「先猜一猜要多长」。

**老师提问卡**

1. 不用公式，你怎么量出「箍一圈」要多长？
2. 圆大一点，铁皮是变长还是变短？和什么有关？
3. 「滚一圈」走的地面长，和「围一圈」的边线长，是不是一回事？

**投屏举手**  
可口头问「谁觉得会比桌面直径长很多？」——正式记录放到步骤 2。

---

### 步骤 2 · 先猜（约 3–4 分钟）

**界面显示什么**

- 明确对象：当前示范圆直径 **d = 4 cm**（可与步骤 3 默认一致），问：滚一圈，地面大约多长？
- 三个大输入槽：**太低 / 最可能 / 太高**（单位 cm），每个槽点开大数字键盘。
- 右侧：「全班猜一猜」举手分布图（柱状，横轴为老师录入的候选值）。

**孩子能做什么**

- 上台填写三个估值（须满足 low < likely < high）。
- 全班：对老师写出的候选值举手；老师在屏上点每个候选旁的 **+ / −** 记人数。

**程序如何反馈**

- 分布图实时变高。
- 不评判对错；底部提示「等会儿滚完再看谁最准」。

**进入下一步条件**

- 三个估值合法提交；老师点「开始动手」。

**老师提问卡**

1. 你的「最可能」大概是直径的几倍？为什么不是 2 倍？
2. 「太高」你敢报到多少？有没有上限感觉？
3. 如果直径变成 8 cm，你的猜测要不要改？怎么改？

**投屏举手记录怎么做**

1. 老师根据孩子口头说的数，点「添加候选」写入如 8、10、12、15。
2. 每个候选右侧：大触控 **+1 / −1**（≥48px），显示人数。
3. 一键生成简易柱状图；匿名（不记谁举的手）。
4. 数据写入本课会话；步骤 7 回看「最接近实测的候选」。

---

### 步骤 3 · 动手（核心，约 8–10 分钟）——滚动细节

**界面显示什么**

- 主舞台：地面水平刻度尺（cm）+ 轮子立在尺上；圆上红点 A 初始贴地。
- wiggle-me：仅启动时轮子左右轻抖 + 手指图标指向轮子/地面，**无自动滚动动画**。
- 直径读数徽章：`d = x.x cm`；直径两端拖点高亮。
- 右侧数据表为空，按钮「加入数据表」禁用至满一圈。
- 滚动进度环：0 → 1 圈。

**孩子能做什么（滚动写细）**

1. **滚动方式（两种等价）**  
   - **按住轮子拖**：水平拖移，轮子边平移边旋转（无打滑：弧长 = 位移）。  
   - **拖地面**：按住刻度尺区域左右拖，相当于移动「地面」，轮子相对滚动（适合固定轮心演示；第 1 版实现「轮心随滚前进」为主，「地面反拖」为增强）。
2. **红点印记**：红点每转过一定角度在地面落一个小印；印记连起来看出「走了一段」。
3. **满一圈自动停**：当 `rollAngle` 达到 2π（允许 2° 内吸附），`rollLocked = true`，不能继续拖过；地面高亮这段长度，并在高亮段两端标读数 → 显示 **周长测量值 C**。
4. **改直径**  
   - 拖圆上直径两端点（或边缘径向拖）改 `d`；  
   - 或点直径徽章 → 大数字键盘输入（2.0–10.0）。  
   - **改 d 后**：清空印记与 `rollAngle`，解锁，提示「直径变了，再滚一次」。
5. **再滚一次**：满圈后按钮「再滚一次」清轨迹重来（同一 d，用于看测量误差——第 1 版可省略误差，C 用精确 πd 但显示保留两位，模拟「量得」）。

**测量值策略（开发约定，待 Wisdom 确认见第 10 节）**  
推荐：**几何上精确滚动**（位移 = πd × 角度比例），表内 C 显示为保留两位小数的值，让比值稳定在约 3.14，避免随机噪声毁掉规律；老师提问卡可口头提「真测量会有误差」。

**程序如何反馈**

- 拖动中：刻度高亮随红点推进；进度环填充。
- 满圈：短震动动画（缩放 1.05 弹回）+ 语音非必须；文字「这一圈的长是 __ cm」。
- 未满圈点「加入数据表」：按钮抖动，提示「先滚满一圈」。

**进入下一步条件**

- 至少成功满圈 1 次；老师或孩子点「去记数据」（进入步骤 4）。也可步骤 3/4 同屏：满圈后直接点「加入数据表」而不切步——**推荐同屏**：步骤 3 与 4 合并为同一 UI，步骤条仍点亮 3，加入第一行后点亮 4。

**老师提问卡**

1. 红点又贴回地面时，说明什么？
2. 地面这段长，和铁皮箍一圈的长，是什么关系？
3. 只滚半圈，能不能当周长？为什么？

**投屏举手**  
可选：滚完问「和你猜的最可能比，偏长还是偏短？」老师记 偏长/偏短/接近 三柱。

### 步骤 4 · 数据自动记录（约 5 分钟）

**界面显示什么**

- 与步骤 3 同屏；右侧表激活。
- 按钮「加入数据表」（≥48px 高）。

**孩子能做什么**

- 满圈后点「加入数据表」→ 新增一行（d、C、C÷d 自动算，比值保留两位小数）。
- 改直径 → 重滚满圈 → 再加入；目标 **至少 3 行**，鼓励 4–5 行（不同 d）。
- 删「最后一行」（误触防护，不提供清空单行中部）。

**程序如何反馈**

- 新行高亮 1 秒；比值列用同一色，便于扫视「是不是差不多」。
- 若两行 d 相差 < 0.3：弱提示「换一个差得多一点的直径，规律更明显」。
- 满 3 行后，「找规律」按钮亮起。

**进入下一步条件**

- `table.length >= 3` 且每行均有有效 ratio。

**老师提问卡**

1. 看看「周长÷直径」这一列，什么没怎么变？什么变了？
2. 直径越大，周长怎么变？比值呢？
3. 如果有一行比值差很多，可能是什么原因？（测量/没滚满）

**投屏举手**  
老师问：「比值是不是都在 3 左右？」举手同意 → 记一笔（步骤 5 铺垫）。

### 步骤 5 · 找规律（约 5 分钟）

**界面显示什么**

- 主舞台可缩小；右侧/中央出现填空卡（大字）：  
  **「周长大约是直径的 ___ 倍」**  
  下方句式：**「我发现 ______，因为 ______。」**
- 数据表只读可见；比值列可点「排序」按 ratio 排（可选）。

**孩子能做什么**

- 点空白 → 大键盘或预设芯片：`3` / `3倍多一些` / `3.14` / `约3.14` / 自定义。
- 完成两句填空（触控文本：短句芯片拼接 + 少量自打）。

**程序如何反馈**

- **不直接判对错**；若填 `2` 或 `4`：把表中 C 与 2d、4d 虚线对照，让矛盾自己出现（Desmos 式响应反馈）。
- 填「3」「3倍多一些」「约3.14」「3.1」等：亮「可以揭示名称了」。
- 校验规则（宽松）：`patternBlank` 规范化后匹配 `/^(约)?3(\.1|\.14|\.1416)?(倍)?(多一些)?$/` 或包含「3倍多」。

**进入下一步条件**

- 倍数字空通过宽松校验，且「我发现 / 因为」两框非空（或老师强制下一页并记「未填完整」）。

**老师提问卡**

1. 「大约 3 倍」和「正好 3 倍」差在哪？古人说「周三径一」是什么意思？
2. 为什么不同的圆，倍数却差不多？
3. 只用一行数据够不够下结论？为什么要多测几个？

**投屏举手记录怎么做**

- 老师给出芯片选项：`不到3` / `正好3` / `3倍多一些` / `4倍左右`。  
- 全班举手，+1/−1 记入分布；课后对照正确方向「3倍多一些」。

### 步骤 6 · 揭示 + 命名（约 5 分钟）

**界面显示什么**

- 出现术语：**圆周率**，字母 **π**；说明：任意圆周长与直径的比值是固定的数；无限不循环小数；应用常取 **π ≈ 3.14**（与教材一致）。
- 公式首次出现（此前禁止）：  
  **C = πd**　　**C = 2πr**
- **活公式**：当前 `d`、`r` 写入公式并高亮数字，例如  
  `C = 3.14 × **4** = **12.56**`  
  `C = 2 × 3.14 × **2** = **12.56**`  
  改 d 时两式同步变（单一数据源）。
- 短数学史条（可点开）：「周三径一」；祖冲之把 π 精确到小数点后 7 位（不展开长文）。

**孩子能做什么**

- 拖 d，看活公式数字跳变；对照数据表比值。
- 点「用半径算」切换强调 `C = 2πr`（自行车例铺垫）。

**程序如何反馈**

- 公式区与轮子、表绑定同一 `d`；高亮变更的数字（短暂放大）。
- `piRevealed = true` 后，步骤 3–5 回看仍可见公式（只读）。

**进入下一步条件**

- 点「用新圆验证一下」。

**老师提问卡**

1. π 是「正好 3.14」还是「约等于 3.14」？为什么作业里常写 3.14？
2. 已知直径会用哪条公式？已知半径呢？把直径当半径代进去会怎样？
3. C = πd 和 C = 2πr 为什么是一回事？（回到 d = 2r）

**投屏举手**  
快问：「π 取 3.14 是精确值吗？」举手「是/不是」——用于点出易错点。

### 步骤 7 · 反向验证（约 5–6 分钟）

**界面显示什么**

- 任务 A：系统给出**新直径**（如 d = 5 cm 或老师输入），孩子**先算**预测周长，再滚轮验证。  
- 任务 B：教材情境迁移——**自行车轮**（例 3）：半径约 33 cm；问转 1 圈大约走多远（可用缩放示意：屏上轮半径按比例缩小，读数仍标 33 cm）。结果保留整米数的思路用提示卡引导，不替孩子算完。  
- 底部：「回到猜一猜」对照步骤 2 分布，高亮最接近实测的柱。

**孩子能做什么**

1. 输入预测 C → 锁定预测 → 滚动满圈 → 显示实测与预测差（绝对值与「偏多/偏少」）。
2. 自行车：输入或确认 r = 33 → 用活公式算 → 看「约 2 m」量级动画（轮子滚过标尺）。
3. （可选）独轮车钢丝：d = 40 cm，路程 50.24 m，约多少周——用 `路程 ÷ C` 计算器小部件（步骤 7 末可选关卡）。

**程序如何反馈**

- 预测与实测相差 ≤ 2%：显示「对上了」。  
- 偏差大：提示检查是否用了半径当直径。
- 步骤 2 分布图复现，标注实测值竖线。

**进入下一步条件**

- 至少完成一次「先算再滚」；老师点继续。

**老师提问卡**

1. 先算再滚，和先滚再看，哪一步更像「用规律」？
2. 直径翻倍，周长怎么变？面积会怎样？（钩子，不展开）
3. 谁的「最可能」最接近？他当时是怎么想的？

**投屏举手**  
「预测偏长 / 偏短 / 几乎准」三选一举手记分布。

### 步骤 9 · 延伸与彩蛋（约 4–5 分钟）

**界面显示什么**

- 钩子文案：「下一课我们会问——围住的**面**有多大？」→ 指向圆面积探究单。
- **彩蛋 A：割圆术**  
  - 圆内接正多边形，边数滑块：**6 → 12 → 24 → 48 → 96**（步进按倍增）。  
  - 显示多边形周长 Pₙ 与圆周长 C 的逼近；比值 Pₙ/d 逼近 π。  
  - 短注：刘徽割圆术（点开）；不要求计算。
- **彩蛋 B：正方形周长 vs 圆周长**  
  - 同一「外接/内接」对照：边长 a = d 的正方形周长 **4a = 4d**，圆周长 **πd ≈ 3.14d**，并排数字与图。  
  - 一句话：围得越「圆」，同样宽度下边线比 4 倍直径短一截（直觉，不上升理论）。

**孩子能做什么**

- 拖边数看逼近；切换正方形对照。
- 打开易混并排玩半径（面积公式可显灰提示「下节再学」）。

**程序如何反馈**

- 边数增大，多边形描边逼近圆；差值 |C − Pₙ| 缩小的读数。
- 不自动改掌握度；只记「看过割圆术彩蛋」。

**进入下一步条件**  
本课结束；「完成探究」写回证据（第 8 节）。

**老师提问卡**

1. 正六边形周长和圆比，谁更长？边数变多时谁在靠近谁？
2. 为什么正方形周长是 4 个直径，圆却不到 4 个？
3. 周长在「边」上，面积在「面」上——调半径时，谁变快？（引到易混并排）

**投屏举手**  
「96 边形的周长还比圆短吗？」——看图回答。

## 6. 易混并排（周长 vs 面积）

| 项 | 说明 |
| --- | --- |
| 对应关系 | 知识点易混边：周长含义/公式 ↔ 圆面积（`6a-05-04`/`6a-05-06` ↔ `6a-05-08`） |
| 何时出现 | 默认 **步骤 9** 手动打开；老师可在步骤 6 后任意时刻用顶栏「对比」打开。步骤 5 前不出现面积，以免干扰倍数发现。 |
| 怎么切换 | 顶栏切换「单圆探究 / 周长∥面积」；或步骤 9 按钮。关闭回到原步骤布局。 |
| 布局 | 同一圆、**同一半径滑块**；**左**：周长（圈边高亮 + C=2πr 活公式）；**右**：面积（圆面涂色 + S=πr² 活公式，标注「下节课正式探究」）。 |
| 孩子能做 | 只拖一个 r（或 d）；左右同步变。 |
| 本课深度 | **只演示不讲**面积推导；不要求填面积结论；不进面积数据表。 |
| 反馈 | 可显示「r 变大时，面积数字跳得比周长更猛」的弱提示（一次），不展开平方意义。 |

## 7. 触摸与无障碍

| 要求 | 做法 |
| --- | --- |
| 多点触控 | 允许两指：例如一人拖直径一端，另一人拖另一端；或一人滚轮、一人点「加入数据表」。命中测试按 pointerId 分流，互不抢同一手势。 |

## 9. 验收清单（可测，一行一条）

1. 启动后画面静止，仅有一处 wiggle-me 指向可滚轮子，无自动播放滚动。  
2. 步骤 0 可将 r 与 d 联动，且能完成「d = 2r」选择。  
3. 步骤 2 三个估值满足 low < likely < high 才能继续；举手候选支持 +1/−1 并显示柱状分布。  
4. 按住轮子拖可滚动；红点在地面留下印记；位移与转角满足无打滑关系。  
5. 滚满一圈自动停止，地面高亮段长度读数等于当前周长测量值（保留两位小数）。  
6. 未满一圈无法加入数据表；满圈后可加入，表行含 d、C、C÷d（两位小数）。  
7. 拖直径或键盘改 d（限 2.0–10.0），改后轨迹清空且需重滚。  
8. 至少 3 行数据后才可进入步骤 5 找规律。  
9. 步骤 5 前界面**不出现** π、C=πd、C=2πr 字符。  
10. 填空「周长大约是直径的 ___ 倍」在宽松规则下接受「3倍多一些」「约3.14」等；填 2 或 4 时用对照反馈而非简单打叉。  
11. 步骤 6 揭示后活公式中的数字随 d 实时变化，且与轮子、表同一数据源。  
12. 步骤 7 支持先输入预测再滚动，并显示对比；能回看步骤 2 举手分布与实测竖线。  
13. 学生模式下右上角提问卡不可见；老师模式可见且每步 ≥2 条问题。  
14. 步骤 9 正多边形边数含 6 及倍增至 96，多边形周长可视化逼近圆周长。  
15. 步骤 9 可开正方形周长 4d 与圆周长 πd 并排数字。  
16. 易混并排：同一 r，左周长右面积公式同步；面积侧有「下节再学」标注。  
17. 所有主按钮与拖点命中区 ≥48px；数字输入不依赖物理键盘。  
18. 支持双 pointer 同时操作而不丢失其中一手势。  
19. 撤销可回退最近的 d 变更或表行加入；重置需二次确认。  
20. 探究结束写入证据事件，且**不会**自动修改学生掌握度字段。  
21. 图形为 SVG 参数绘制，不含位图轮子素材。  
22. 在 1920×1080 与常见一体机分辨率下 16:9 布局无遮挡关键读数；3 米外主数字可读（人工看一眼验收）。

## 10. 待讨论（需 Wisdom 拍板）

1. **测量值要不要加噪声？** 精确 πd 利于发现规律；真误差更「实验」。是否采用「精确值 + 口头强调误差」，还是 ±1% 抖动？  
2. **步骤 3 与 4 是否同屏？** 本稿推荐同屏；若希望步骤条严格一屏一事，可拆。  
3. **绕绳量法**是否做进 MVP，还是只滚动 + 文案提及？  
4. **自行车 r = 33 cm** 在屏上如何缩放：示意缩小但标注真值，是否接受？  
5. **π 展示位数**：课内统一 3.14，还是活公式提供「3.14 / 更精确」切换？  
6. **举手记录**是否需要持久化到班级名册，还是仅当堂会话？  
7. **割圆术**边数是否允许从 6 拖到任意偶数，还是只允许 6,12,24,48,96？  
8. **易混并排**是否允许在步骤 7 就出现，还是严格锁到步骤 9？  
9. **完成探究写回**：证据是否按学生姓名记（上台孩子），还是只记「本班本课」？  
10. **例题编号**：知识树按例 1 量周长 / 例 2 实验填表 / 例 3 自行车还原；若纸书圈号不同，以纸书为准改文案引用。

## 11. 已拍板

对应第 10 节的 10 条待讨论，Wisdom 已拍板如下；M1 实现以此为准。

| # | 待讨论项 | 决定 | 实现落点 |
| --- | --- | --- | --- |

## 附录 A · 文案用词（与教材对齐，勿自造）

- 圆心 O、半径 r、直径 d；直径长度是半径的 2 倍。  
- 围成圆的曲线的长 → **圆的周长**。  
- 周长与直径的比值是固定的数 → **圆周率** π；应用常取 π ≈ 3.14。  
- 公式书写：`C = πd` 或 `C = 2πr`。  
- 实验发现表述方向：原来一个圆的周长总是它的直径的 **3 倍多一些**。  
- 情境词：箍铁皮、滚动、绕绳、自行车轮转 1 圈走多远。
