## 2. 教学目标与结论

**一句话教学目标：**  
让孩子把圆等分、剪开、拼合，观察「份数越多越接近长方形（或三角形）」，通过数据表自己发现拼出图形的长 ≈ πr、宽 = r，从而推出 S = πr²，并会用公式求圆、圆环与方圆组合的面积。

**孩子最后要自己填出的结论（程序不先给）：**

1. 填空：拼成的长方形，**长 ≈ ___**，**宽 = ___**。（期望：长 ≈ 圆周长的一半 = πr；宽 = 半径 r）
2. 句式：「我发现 ______，因为 ______。」  
   期望大意：份数越多，拼出的图形越像长方形；长方形的面积 = 长 × 宽 = πr × r，所以圆的面积 = πr × r。
3. 揭示后能复述：圆的面积公式 **S = πr²**；r² 表示 r × r；已知直径要先求半径；圆环面积 = 外圆面积 − 内圆面积。
4. （拆三角形路线）能说出：每一小份近似三角形，底是周长的 1/n，高是 r；n 个加起来是 ½ × C × r = ½ × 2πr × r = πr²，结果一样。

### 4.2 派生量（只读计算）

| 派生 | 公式 / 规则 |
| --- | --- |
| `d` | `2r` |
| `C` | `2πr`（内部 `Math.PI`；**展示**统一 3.14 与教材一致；老师模式可切 3.1416，主计算不变，沿用周长稿已拍板第 5 条） |
| `S` | 内部真值 `Math.PI × r²`；**界面上的「精确面积」**一律用教材口径 `3.14 × r²`（老师可切显示 3.1416，主计算仍 3.14） |
| `sectorAngle` | `2π / n` |
| `rectLength` | 拼成长方形的**长**（近似值）= `n/2` 份的弧长之和 = `C/2 = πr`；显示时按 **当前 n 的实际拼合几何** 计算：`n/2 × 2r·sin(π/n)`（以弦长计，让「n 越大越接近 πr」在数字上真的可见） |
| `rectWidth` | 拼成长方形的**宽** ≈ `r`；显示时取 `r·cos(π/n)`（弓高影响，n 越大越接近 r） |
| `rectArea` | `rectLength × rectWidth`（数据表「面积近似值」，保留两位） |
| `triBase` | 拆三角形路线：单份底 = `C/n`（显示时用弦长 `2r·sin(π/n)`） |
| `triHeight` | 单份高 = `r·cos(π/n)` |
| `triSumArea` | `n × ½ × triBase × triHeight`（保留两位；n 增大逼近 πr²） |
| `gapToTrue` | `S展示 − rectArea`（或 `S展示 − triSumArea`）。「精确 / 还差多少」的基准是界面展示用的 **3.14 × r²**（`formulaS`），不是内部 `Math.PI × r²`。n = 128 时与 3.14×r² 的差 < 0.02 cm²（彩蛋文案依据）；若按 Math.PI，r=4、n=128 差约 0.0202，会卡在门槛外。 |

**数值策略**：数据表的近似值用**弦长 / 弓高的真实几何值**，不加随机噪声；这样 n = 8 → 128 时面积近似值单调逼近 πr²，孩子能看到「份数越多越接近」（教材原话）。揭示后显示的精确值是 **3.14 × r²**（不是 Math.PI），与活公式、验证、猜一猜对照同一口径。

### 4.3 数据表行结构

```text
Row {
  id: string
  n: number            // 等分数，加入时快照
  r: number            // cm，加入时快照
  assembly: "rect" | "tri"
  length: number       // cm，rect：长（近似）；tri：底 C/n
  width: number        // cm，rect：宽（近似）；tri：高 r
  areaApprox: number   // cm²，rect：长×宽；tri：n × ½ × 底 × 高
  source: "assemble"   // 本课只允许拼合到位（assembleT = 1）后加入
}
```

表头随拼法切换：  
- `rect`：`# | 等分数 n | 长 ≈ /cm | 宽 /cm | 面积 ≈ /cm²`  
- `tri`：`# | 等分数 n | 每份底 /cm | 每份高 /cm | n 份合计 ≈ /cm²`  
同一张表可混放两种拼法的行（用小图标区分），便于步骤 5 比较「两条路算出来差不多」。

### 步骤 0 · 回忆（约 2 分钟）

**界面显示什么**

- 主舞台并排两个**迷你可视化**（嵌入模式：只显示核心操作，隐藏步骤条与情境条，见 `area-chain.md` 第 6 节）：  
  - 左：**长方形面积**（`area-chain.md` 第 1 站）——网格上一个长方形，长、宽各一个拖点；旁注 `S = 长 × 宽 = __ × __ = __`。  
  - 右：**三角形面积**（`area-chain.md` 第 3 站）——一个三角形，点「拼」出现第二个全等三角形拼成平行四边形；旁注 `S = ½ × 底 × 高`。
- 短提示：「长方形的面积 = ____ × ____；三角形的面积 = ____ × 底 × 高。」
- 右侧：迷你任务卡；同时显示一行小字回忆 `C = 2πr`（上一课结论，只读）。

**孩子能做什么**

- 拖长方形的长或宽，看格子数与算式同步。
- 点三角形的「拼」，看两个全等三角形合成平行四边形；点选填空：`½` / `1` / `2`（三选一大按钮）。
- 点选长方形填空：`长 × 宽` / `长 + 宽` / `边 × 4`。

**程序如何反馈**

- 拖动时旁注数字实时变，格子数与「长 × 宽」同时高亮（数形结合，`M-10`）。
- 选对：对应算式闪一下青绿；两题都对则解锁「下一步」。
- 选错：不弹「错了」；长方形错选「长 + 宽」时把周长描边高亮与面积涂色并排，让孩子自己看差别；三角形错选「1」时把第二个三角形涂成半透明，让「多了一个」自己出现。

**进入下一步条件**

- 两个填空均正确，或老师点「跳过回忆」（记日志 `step0_skipped_by_teacher`）。

**老师提问卡（2–3 条）**

### 步骤 3 · 动手（核心，约 10 分钟）——剪、移、拼细节

**界面显示什么**

- 主舞台：网格底；左「原圆」（r = 4，默认 n = 8，未剪，各份两色交替填充但无缝）；右「拼合区」空白，画一条虚线轨道示意目标位置。
- wiggle-me：仅启动时「剪」按钮轻抖 + 手指图标指向它，**无自动播放**。
- 半径读数徽章：`r = 4.0 cm`；半径端点拖点高亮。
- 控件条：等分数 n 分段按钮（8 高亮）、拼合进度滑块（0）、「剪 / 移 / 拼」三按钮（移、拼在剪前禁用）。
- 右栏：拼法默认「拼成长方形」高亮；「拆成三角形」可切；数据表空，「加入数据表」禁用至拼合到位。

**孩子能做什么（写细）**

1. **剪**：点「剪」→ 原圆沿 n 条半径出现细白缝（0.4 秒依次划出，非一次全出），`cutDone = true`，「移」「拼」解锁。
2. **移**：点「移」→ 各份在原位轻微炸开（径向外移 0.2r），显示每份是一个近似三角形；再点一次收回。用于让孩子看清「一份」长什么样。
3. **拼**（两种等价方式）  
   - **拖拼合进度滑块**：0 → 1，各份沿各自轨道**同时**从原圆位置平移 + 旋转到拼合区目标位置；滑块可来回拖，随时停在半路观察。  
   - **点「拼」**：程序自动把 `assembleT` 从当前值走到 1（1.2 秒，可再点一次回到 0）。  
   - **`rect` 拼法目标位置**：n 份分两排，上排 n/2 份尖朝下、下排 n/2 份尖朝上交错咬合，排成一个近似长方形；上下两排底边（弧）分别构成长方形的上下长边。上排相对下排错开半份，两端各露出半份弧（n = 8 时端头凸出明显，正是「毛毛的」直观）。外框按 `n/2 × 弦长` **居中**画在咬合区上，不包进两端半份。  
   - **`tri` 拼法目标位置**：n 份沿一条水平线排开成一排「锯齿」，每份底（弧）朝下、尖朝上；点任意一份可放大看「底 ≈ C/n、高 ≈ r」。
4. **改 n**：点 8 / 16 / 32 / 64 → 原圆重新等分，`cutDone` 重置、`assembleT` 归零、拼合区清空，提示「份数变了，再剪再拼」。已加入的表行**不受影响**。
5. **改 r**：拖半径端点或点徽章键盘输入（2.0–6.0）→ 圆整体缩放；同样重置 `cutDone` 与 `assembleT`。**改 r 会把拼合区清空**，因为拼出的图形尺寸随 r 变——此行为要写明；若拼合到位后想比较不同 r，先加入数据表再改。
6. **半路观察**：拼合进度停在 0.5 时，各份悬在半空；n = 8 时能看到「拼出来还很凹凸」，n = 64 时「几乎就是长方形」——这是本步最重要的直观。

**程序如何反馈**

- 拼合到位（`assembleT = 1`）：拼合区图形四周浮出**近似长方形的外框**（青绿虚线，按 `n/2 × 弦长` 居中，两端半份弧可露出框外），标注「长 ≈ ?」「宽 = ?」，两处「?」在步骤 5 前不显示数字，只显示可点开的**尺子**：点长边 → 沿长边贴一把尺子读出长度；点宽边 → 读出宽度（读数为 4.2 派生量）。
- 「加入数据表」解锁；n 越大，外框与拼合图形之间的锯齿空隙越小，程序在框旁给一行小字「凹凸的地方越来越小了」（每档 n 只提示一次）。
- 未到位点「加入数据表」：按钮抖动，提示「先拼到位」。
- `tri` 拼法到位：整排锯齿下方浮出一行 `n 个三角形`；点任一份放大，底和高各标一把尺子。

**进入下一步条件**

- 至少完成 1 次拼合到位；老师或孩子点「去记数据」。**推荐步骤 3 与 4 同屏**（同周长稿已拍板第 2 条）：步骤条先点亮 3，加入第一行后点亮 4。

**老师提问卡**

1. 剪开的每一小份像什么图形？份数越多，它越像什么？
2. 拼出来的图形上下边为什么是「毛毛的」？怎么让它更平？
3. 拼的时候面积变了吗？变的是什么？没变的是什么？（转化的核心）

**投屏举手**  
「拼到 16 份时，你觉得它像不像长方形？」老师记 像 / 不像 / 说不准 三柱；到 64 份再举一次，对比两次分布。

### 步骤 4 · 数据自动记录（约 5 分钟）

**界面显示什么**

- 按钮「加入数据表」（≥48px 高）。

**孩子能做什么**

- 拼合到位后点「加入数据表」→ 新增一行（n、长 ≈、宽、面积 ≈ 自动算，保留两位）。

- 切到「拆成三角形」再加 1–2 行，看两条路合计值是否接近。

**程序如何反馈**

**进入下一步条件**

**老师提问卡**

2. 「宽」这一列呢？它一直是多少？
3. 面积近似值越来越接近一个数——这个数是圆的什么？

**投屏举手**

### 步骤 5 · 找规律（约 5 分钟）

**界面显示什么**

- 主舞台缩小到 1/2，保留拼合到位的最大 n 图形与外框；右侧/中央出现填空卡（大字）：  
  **「长 ≈ ______，宽 = ______」**  
  下方句式：**「我发现 ______，因为 ______。」**
- 数据表只读可见。

**孩子能做什么**

- 点「长」空白 → 预设芯片：`周长的一半` / `C ÷ 2` / `πr` / `直径` / `周长` / 自定义（大键盘）。
- 点「宽」空白 → 预设芯片：`半径` / `r` / `直径` / `d` / 自定义。
- 完成两句填空（短句芯片拼接 + 少量自打）。

**程序如何反馈**

- **不直接判对错**；若「长」填 `周长` 或 `直径`：把拼合图形长边与一条与 C（或 d）等长的对照线段并排叠放，让长短差异自己出现；若「宽」填 `直径`：在拼合图形上叠一条 d 长的竖线，明显伸出去。
- 「长」通过：`周长的一半`、`C÷2`、`πr`、`π×r`、`3.14×r`、`半周长`；「宽」通过：`半径`、`r`。规范化后匹配（去空格、全角转半角、大小写不敏感）：  
  - 长：`/^(周长的一半|半周长|c÷2|c\/2|πr|π×r|π\*r|3\.14×?r|3\.14\*r)$/`  
  - 宽：`/^(半径|r)$/`
- 两空都通过：亮「可以揭示公式了」。

**进入下一步条件**

- 两空通过宽松校验，且「我发现 / 因为」两框非空（或老师强制下一页并记 `step5_forced_by_teacher`）。

**老师提问卡**

1. 长方形的长为什么是周长的「一半」而不是周长？上排和下排各占了多少？
2. 如果拼出来的长方形长是 πr、宽是 r，面积怎么算？把「长 × 宽」写出来。
3. 只看 n = 8 那一行能下这个结论吗？为什么要看到 64？

**投屏举手记录怎么做**

- 老师给出芯片选项：`长是周长` / `长是周长的一半` / `长是直径` / `说不准`。
- 全班举手，+1/−1 记入分布；课后对照正确方向「周长的一半」。

### 步骤 6 · 揭示 + 命名（约 5 分钟）

**界面显示什么**

- 拼合图形外框上「长 ≈ ?」「宽 = ?」替换为 **长 ≈ πr**、**宽 = r**（与教材 p65 填空同向）。
- 推导链逐行出现（点一下出一行）：  
  `长方形的面积 = 长 × 宽`  
  `圆的面积 = πr × r`  
  **`S = πr²`**（首次出现；此前禁止）
- 旁注：`r²` 读作「r 的平方」，表示 `r × r`（与五上 `5a-09` 呼应，一句话不展开）。
- **活公式**：当前 `r` 写入并高亮，例如  
  `S = 3.14 × **4** × **4** = **50.24**`  
  改 r 时数字同步跳变（单一数据源）；n 也同步：`n = 64 时拼出 ≈ 50.20，精确 50.24`，让「越多越接近」到揭示后仍能看见。
- 「拆成三角形」路线的对照卡（可点开）：  
  `n 个三角形 = n × ½ × (C ÷ n) × r = ½ × C × r = ½ × 2πr × r = πr²` —— 两条路殊途同归。
- 短数学史条（可点开）：刘徽「割之弥细，所失弥少」——教材 p66「你知道吗」（不抄原文，一句话）。

**孩子能做什么**

- 拖 r，看活公式数字跳变；对照数据表最后一行的面积近似值。
- 切 n 看「拼出 ≈」与「精确」的差缩小。
- 点开三角形路线对照卡。

**程序如何反馈**

- 公式区与拼合图形、表绑定同一 `r`、`n`；高亮变更的数字（短暂放大）。
- `formulaRevealed = true` 后，步骤 3–5 回看仍可见公式（只读）。

**进入下一步条件**

- 点「用新圆验证一下」。

**老师提问卡**

1. `r²` 是 `r × 2` 吗？r = 4 时 `r²` 是多少？
2. 已知直径 d = 10，能直接代进 `S = πr²` 吗？先要做什么？
3. 两条路——拼长方形、拆三角形——为什么最后都是 πr²？

**投屏举手**  
快问：「r = 4 时，r² 等于 8 还是 16？」举手——用于点出 `r²` 与 `2r` 的易错点。

### 步骤 7 · 反向验证（约 5 分钟）

**界面显示什么**

- 任务 A：系统给出**新半径**（如 r = 5 cm 或老师输入），孩子**先算**预测面积 → 锁定 → 点「拼」用 n = 64 拼合 → 显示拼出近似值与精确值、预测值三者对比。
- 任务 B：教材 p66 做一做迁移——**圆形桌面直径 1 m** 求面积：先把 d 换成 r（大按钮「d → r」），再算；屏上按比例示意并标「示意」。
- 任务 C：教材 p65 情境回收——**草坪直径 20 m、每平方米 8 元**：先求面积再求钱，用两格计算器小部件，不替孩子算完。
- 底部：「回到猜一猜」对照步骤 2 分布，**高亮最接近精确值的柱 + 标注精确值**（候选是分类轴，不画竖线）。

**孩子能做什么**

1. 输入预测 S → 锁定预测 → 拼合到位 → 显示预测与精确值之差（绝对值与「偏多/偏少」）。
2. 任务 B/C：按提示分步输入。
3. 回收步骤 2 提问卡第 2 条：把 r 从 2 拖到 4（或 3 → 6），看面积变成 4 倍而不是 2 倍。r 范围是 2.0–6.0，无法从 4 拖到 8，不用 4→8 作演示。

**程序如何反馈**

- 预测与精确值相差 ≤ 2%：显示「对上了」。
- 偏差大且预测 ≈ 2πr（= πd = π × 2r，数值相同，分不出「算成周长」还是「把 r² 当成 2r」）：合并一句提示「你算的可能是周长；r² 是 r × r，不是 r × 2」；预测 ≈ πd²：提示「用的是直径还是半径？」。
- 步骤 2 分布图复现，标注精确值并高亮最接近的柱。
- 半径翻倍用文字卡对照：r = 2 → 4、r = 3 → 6，面积都 ×4（不把滑块拖出 2.0–6.0 范围）。

**进入下一步条件**

- 至少完成一次「先算再拼」；老师点继续。

**老师提问卡**

1. 先算再拼，和先拼再看，哪一步更像「用规律」？
2. 半径变成 2 倍，面积变成几倍？周长呢？为什么不一样？（引到易混并排）
3. 谁的「最可能」最接近？他当时把圆想成了什么？

**投屏举手**  
「预测偏多 / 偏少 / 几乎准」三选一举手记分布。

### 步骤 9 · 延伸与彩蛋（约 5 分钟，可切到下一课时）

**界面显示什么**

- 钩子文案：「六下我们会问——把圆『立起来』变成圆柱，体积怎么算？」→ 指向六下圆柱体积（树上暂无节点，只留文案）。
- **延伸 A：圆环（例 2，`6a-05-09`）**  
  - 同一原圆，叠一个同心小圆，内半径 `rInner` 可拖（0.5 ≤ rInner ≤ r − 0.5）；环形区域涂色。  
  - 活公式两式并列：`S环 = πR² − πr² = __ − __ = __` 与 `S环 = π(R² − r²) = 3.14 × (__ − __) = __`，对应教材小丽 / 小明两种算法；数字同步。  
  - 情境：光盘（内 2 cm、外 6 cm）一键填入。  
  - 易错拦截：孩子若输入 `π(R − r)²`，画出一个半径为 (R − r) 的小圆与圆环并排，让面积差自己出现。
- **延伸 B：外方内圆 / 外圆内方（例 3，`6a-05-10`，用到 `5a-08`）**  
  - 切换按钮「外方内圆」「外圆内方」；同一个 r 可拖。  
  - 外方内圆：正方形边长 = 2r，`S方 = (2r)² = 4r²`，`S圆 = πr²`，差 = `4r² − πr² = 0.86r²`（r = 1 时 0.86 m²）。  
  - 外圆内方：正方形对角线 = 2r，点「拆成三角形」把正方形拆成 2 个三角形（底 2r、高 r），`S方 = 2 × ½ × 2r × r = 2r²`，差 = `πr² − 2r² = 1.14r²`（r = 1 时 1.14 m²）。  
  - 一行结论卡让孩子填：正方形面积是 r² 的 **___** 倍（外方：4；内方：2）；圆面积是 r² 的 **___** 倍（3.14）。
- **彩蛋 n = 128**：老师模式或 n = 64 长按 3 秒解锁；拼出 ≈ 与精确值差 < 0.02 cm²，文案「割之又割，以至于不可割」。
- **易混并排入口**：按钮「面积和周长有什么不同？」（见第 6 节）。

**孩子能做什么**

- 拖 `rInner` 看圆环面积变化；切换两种算法看结果相同。
- 切换外方 / 外圆，拖 r 看「0.86r²」「1.14r²」的系数不变。
- 打开易混并排玩半径。

**程序如何反馈**

- 圆环：`rInner → r` 时环变细、面积趋 0；`rInner → 0` 时趋近整圆。
- 方圆：拖 r 时差值数字变但「÷ r²」的系数恒 0.86 / 1.14，程序在系数处加一个「不变」小标。
- 不自动改掌握度；只记「看过圆环 / 方圆 / 128 份彩蛋」。

**进入下一步条件**  
本课结束；「完成探究」写回证据（第 8 节，事件 `exploration_completed`）。

**老师提问卡**

1. 圆环面积为什么不能用「外半径 − 内半径」再平方？
2. 外圆内方里正方形的边长是多少？为什么要拆成两个三角形来算？（又是转化）
3. 半径变大时，周长和面积谁「跑得快」？为什么？（引到易混并排）

## 6. 易混并排（面积 vs 周长；本课主讲面积）

| 项 | 说明 |
| --- | --- |
| 对应关系 | 知识点易混边：圆面积 ↔ 周长含义/公式（`6a-05-08` ↔ `6a-05-04`/`6a-05-06`）；公式记混（`S = πr²` ↔ `C = 2πr`） |
| 何时出现 | 老师模式随时可开（顶栏「周长∥面积」）；学生模式 **步骤 9** 才出现（沿用周长稿已拍板第 8 条）。步骤 5 前不出现周长公式字母，以免干扰「长 ≈ πr」的发现——但 `C = 2πr` 作为上节课结论可在步骤 0、4 以数字形式出现。 |
| 怎么切换 | 顶栏切换「单圆探究 / 周长∥面积」；或步骤 9 按钮。关闭回到原步骤布局。 |
| 布局 | 同一圆、**同一半径滑块（自绘 SVG，拖柄 ≥ 48px）**；**左**：面积（圆面涂色 + `S = πr²` 活公式，本课主角，正常色）；**右**：周长（圈边高亮 + `C = 2πr` 活公式，上节课结论，正常色但标「上节课」）。与周长稿左右**对称互换**：那边周长在左、面积在右显灰；这边面积在左、周长在右。 |
| 孩子能做 | 只拖一个 r；左右同步变。 |
| 本课深度 | 面积为主；周长只作对照，不重推。重点让孩子看到：r 翻倍，周长 ×2，面积 ×4。 |
| 反馈 | r 从 2 → 4（或 3 → 6）时给一次性弱提示「面积 ×4，周长 ×2」；`r²` 处高亮一次。r 上限 6.0，不用 4→8。 |

## 附录 A · 文案用词（与教材对齐，勿自造）

- 把圆分成若干（偶数）等份，剪开后拼一拼；分的份数越多，每一份就越小，拼成的图形就越接近于一个长方形。
- 长方形的长近似于圆周长的一半（πr），宽近似于半径（r）。
- 长方形的面积 = 长 × 宽，所以圆的面积 = πr × r = πr²。
- 如果用 S 表示圆的面积，圆的面积计算公式：`S = πr²`。
- 圆环面积 = 外圆面积 − 内圆面积；两种算法：`πR² − πr²` 与 `π(R² − r²)`。
- 外方内圆：正方形边长与圆的直径相等；外圆内方：正方形可看成两个三角形，底 2r、高 r。
- 情境词：圆形草坪、草皮、光盘、圆形桌面、环岛、铜镜。
- 不用「扇形」称呼剪开的小份（扇形是第 4 节内容）；统一说「一份」「近似三角形的小纸片」。
