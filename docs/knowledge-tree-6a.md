## 5. 母题线索（每节例题与做一做题型，一行一个）

### 分数乘法
- 几个相同分数相加 → 分数×整数  
- 求一个数的几分之几（乘法）  
- 分数×分数（折纸理解）  
- 分数乘法计算（含先约分）  
- 小数×分数  
- 用运算律使分数乘法简便  
- 分数连乘 / 混合运算  
- 连续求一个数的几分之几（分步或综合）  
- 求比一个数多（少）几分之几的数  
- 做一做：桶水几倍与一半对照；只列式的分数×分数；蜂鸟飞行；剪纸用纸；科学家人数等  

### 位置与方向（二）
- 根据“某方向偏角 + 距离”描点  
- 在图上读出方向与距离  
- 根据文字描述标出多个地点  
- 描述并补全折线路径（含台风路径）  
- 互逆方向表述  
- 做一做：校园平面图标注；根据同伴描述画路线  

### 分数除法
- 判断 / 求倒数  
- 分数÷整数（折纸平均分）  
- 整数/分数÷分数（×倒数）  
- 连续除法实际问题（含药、装瓶）  
- 已知一个数的几分之几求这个数  
- 已知比一个数少几分之几求这个数  
- 和倍（分数倍）问题  
- 工程问题（合作时间）  
- 做一做：两车运货次数；航模人数分配等  

### 比
- 写出比、求比值、比的读写  
- 比与除法、分数互化  
- 化简比（整数 / 小数 / 分数）  
- 按比分配求各部分数量  
- 做一做：补全比；配制稀释液；三量之比（水泥沙子石子）  

### 圆
- 辨认圆心、半径、直径及关系  
- 用圆规按 r 或 d 画圆  
- 周长测量与 π 的意义  
- 已知 r/d 求周长；已知周长求 d/r  
- 转圈路程 / 滚动周数  
- 圆面积计算  
- 圆环面积  
- 方圆组合（差积）  
- 半圆、组合图形周长与面积  
- 扇形/圆心角辨认；画扇形；扇环面积  
- 做一做：标注 O、r、d；已知周长反求直径；草坪造价；铜镜方圆差  

### 百分数（一）
- 说出百分数含义；读写百分数  
- 分数/小数/百分数互化  
- 求命中率等百分率  
- 求一个数的百分之几是多少  
- 求增加/减少百分之几  
- 求增加/减少百分之几后的数量  
- 连续涨跌比较（假设法）  
- 做一做：达标率；节水百分之几；小学生人数减少 0.5% 等  

### 扇形统计图
- 根据数据算百分比并读扇形图  
- 选择条形/折线/扇形  
- 由扇形图求具体量（已知总量）  
- 做一做：牛奶营养成分；乔木林龄组构成  

### 数学广角
- 连续奇数求和与平方  
- 分数无限逼近 1  
- 图形递推数数（绿蓝正方形、外圈）  
- 做一做：对称奇数和；第 n 个图形有多少个
